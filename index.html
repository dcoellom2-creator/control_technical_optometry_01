Regla de uso oficial

Carpeta raíz vigente: TO90_Ecosistema_Documental en Drive. Las versiones anteriores quedan como respaldo histórico. Kobo captura datos operativos y clínicos, pero el único origen válido para precios, abonos, saldos, ventas, utilidad y cartera es el Sheet económico oficial.

Fuentes conectadas

  • Drive oficial: repositorio raíz del ecosistema.
  • Kobo primer acercamiento: captura de prospectos y empresas.
  • Kobo consulta optométrica: datos clínicos y operativos.
  • Sheet económico oficial: valores reales y análisis financiero.
  • Presentación socios: explicación estratégica del ecosistema.

Configuración WhatsApp

Se guarda solo en este navegador. Si no configuras número, se usa un enlace genérico de WhatsApp.

Publicación recomendada

  1. Sube toda esta carpeta completa a GitHub.
  2. Activa GitHub Pages desde el repositorio.
  3. Abre index.html como página principal.
  4. No borres los HTML modulares: el contenedor depende de ellos.
  5. Cuando tengas enlaces directos de subcarpetas, reemplaza en cada HTML el enlace raíz por el link específico.

Referencias de gestión

Base metodológica: ISO 9001:2015, cláusula 7.5 sobre información documentada; ISO 31000:2018 para gestión basada en riesgo, seguimiento y mejora; sistema TO90 aplicado a dirección, finanzas, ventas, marketing, operación, datos y mejora continua.
